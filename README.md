# Book Tracker – трекер прочитанных книг

**Автор:** Черев Александр Дмитриевич

## Описание

Простое графическое приложение на Python (tkinter) для учёта прочитанных книг.
Позволяет добавлять книги с указанием названия, автора, жанра и количества страниц,
фильтровать список по жанру и по условию «страниц > 200», сохранять и загружать данные
в формате JSON. Программа проверяет корректность ввода и предоставляет удобный табличный вид.

## Инструкция по запуску

1. Убедитесь, что установлен Python 3.6 или новее.
2. Скачайте файл `book_tracker.py` из репозитория.
3. В терминале перейдите в папку с файлом и выполните:
   ```bash
   python book_tracker.py
